# Generic full-device Paramak demonstrator

This directory contains a browser derivative and its source STEP for the
FusionDigital digital-prototype workspace. The geometry was generated with
Paramak 0.9.11 from the repository-local reproducible script
`research/3d/generate_paramak_full_device.py`. The exact script SHA-256,
authoring environment, tessellation settings and converter version are recorded
in `model-manifest.json`.

It is a generic 360-degree parametric tokamak demonstrator. It is not ITER,
EXL-50U, or an engineering-authority model and must not be used for dimensions,
manufacturing, simulation, or safety decisions.

the provenance in `model-manifest.json`.
