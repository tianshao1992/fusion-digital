- 目标：以“关键诊断技术链”为记录单元，而不是把同一诊断的每篇论文拆成独立工作；同时覆盖测量原理、硬件、标定、反演、装置验证、局限及数字孪生价值。

## 1. 来源与纳入规则

本数据集只纳入以下一手来源：

1. 同行评审论文原文及其 DOI；
2. 作者提交的预印本原文；
3. ITER、Fusion for Energy 等装置/项目机构的官方页面或正式技术文件；
4. 软件项目的官方文档或官方代码仓库。

没有把博客、媒体稿、百科、搜索聚合页或论文引用页当作证据。论文 URL 使用 DOI；没有 DOI 的官方文件使用机构原始 URL。代码 URL 只指向代码/软件本身，绝不以论文 URL 代替代码地址。

“代码存在”采取保守定义：

- `official-direct`：由诊断/模型维护团队直接发布，且与该诊断信号链直接相关，例如 FIDASIM；
- `official-enabling`：官方发布但只支撑前向建模、原子数据或探测器响应，例如 OpenADAS、Cherab、Geant4、FreeGS；
- `controlled-access`：真实存在但需许可、授权或出口管制，例如 OMFIT/MCNP；
- `not-public`：论文/装置证明有运行分析链，但没有发现可复核的官方代码发布；此类 URL 强制为 `null`。

## 2. 分类边界

### DG1 磁平衡 / 电流 / 位形

包括磁通环、拾取线圈、罗戈夫斯基、霍尔稳态磁测量、光纤电流传感、MSE 内部磁场约束和实时平衡反演。MSE 虽然是光学诊断，但其主要任务是内部磁场/电流剖面，因此主类为 DG1。rtEFIT 以计算反演为主，但它直接把磁观测转成位形状态，也归 DG1，并关联 DG10/DG11。

### DG2 电子密度 / 温度

包括常规与 LIDAR 汤姆逊散射、干涉/偏振、ECE、剖面反射计。若 ECE/ECEI 主要研究 MHD 或二维涨落，则分别归 DG2 与 DG6：一维绝对/剖面 ECE 主 DG2，二维涨落 ECEI 主 DG6。

### DG3 离子 / 流动 / 组分 / 中性

包括 CXRS/CER、XICS、NPA、主离子同位素谱和 ITER DNB-CXRS。FIDA 虽同样使用电荷交换光谱，但主要目标是快离子相空间，因此归 DG5；NPA 同时关联 DG5，但在本表以离子/中性谱技术链主归 DG3。

### DG4 辐射 / 杂质 / 功率损失

包括测辐射热计、SXR、VUV、可见光杂质/燃料谱和 HXR 逃逸电子监测。SXR/HXR 也可服务 MHD 或高能粒子，但若主观测量是辐射场/制动辐射，主类保持 DG4，再通过 relatedTasks 连接 DG5/DG6。

### DG5 聚变产物 / 中子 / 伽马 / 高能粒子

包括总中子率、径向中子相机、中子谱、活化、伽马谱、FIDA/IFIDA、CTS 和 FILD。这里把“聚变功率计量”和“快离子相空间诊断”放在同一一级类，但在后续网站筛选时应再用标签区分 `neutron-metrology`、`spectroscopy` 和 `fast-ion`。

### DG6 MHD / 波动 / 湍流

包括 Mirnov、ECEI、BES、Doppler/相关反射计、PCI、HIBP 和 GPI。分类依据是主要科学量为模态、涨落、电势或湍流，而不是传感器的物理载体。

### DG7 边界 / SOL / 偏滤器 / PFC

包括探针、IR、偏滤器 TS、Balmer/Stark 谱、QMB、LIBS/LIDS、第一镜/尘埃/侵蚀沉积监测。壁材料工作只要主要目标是等离子体—材料相互作用、表面热/粒子通量或材料迁移，就主归 DG7；只有泵、阀、电源、冷却等工程设备状态才应主归 DG8。

### DG0 / DG9 / DG10 / DG11 的关联用法

- DG0：传感器计量、标定、辐照寿命、健康管理；
- DG9：合成诊断或明确的前向观测模型；
- DG10：层析、联合反演、正则化、数据同化；
- DG11：实时发布、控制/保护接口或 AI 质量门控。

这些是横切能力，不抢占 DG1–DG7 的主要物理任务分类。

## 4. 证据与部署等级

### Evidence level

- E0：需求或概念；
- E1：数值/前向设计；
- E2：台架标定或原型；
- E3：已安装、调试，或已有装置数据但尚不能证明例行服务；
- E4：有明确的装置例行在线使用或长期运行证据。

统计：E1 = 4，E2 = 4，E3 = 15，E4 = 19。此前把 ITER 设计/性能预测及仅有装置离线数据的条目计入 E4；本版已按“例行在线或常规使用须有直接证据”的口径保守降级。

### Deployment level

- D1：概念；
- D2：实验室/原型；
- D3：已安装、调试或稳定离线工作流；
- D4：例行实验或实时服务；
- D5：经正式安全/机器保护治理批准的功能。

统计：D2 = 8，D3 = 15，D4 = 19，D5 = 0。没有任何工作被推断为 D5。即便论文提到“用于保护”或“可实时”，如果没有正式安全等级、审批边界、失效策略和治理证据，也不能标 D5。

## 7. 主要证据风险

### 7.1 论文元数据仍需机器化规范

部分 records 的 `authors` 使用“装置团队”或“首作者 et al.”短写，避免在未读取完整版权页时臆造作者列表。正式 Word 报告和网站引用前，建议以 DOI 通过 Crossref/出版社元数据批量补齐全体作者、卷期、页码和出版日期，并保存 BibTeX/CSL-JSON。此项不影响论文主链接，但影响正式参考文献样式。

### 7.2 “设计完成”不等于“装置运行”

ITER、SPARC、部分 DEMO 工作有强设计与原型证据，却没有等离子体运行验证。当前记录已通过 E/D 等级分开；正文撰写必须避免“已用于 ITER 运行”之类越级表述。

### 7.3 运行软件高度不开放

40 个代码关联项为 `not-public`。这不是证明“没有代码”，而是没有发现可核验的官方公开仓库。装置团队常通过 PCS、MDSplus、内部 GitLab、标定数据库和受控配置发布生产算法。后续合作调研应单列：

- 源码是否可获得；
- 配置/标定是否可导出；
- 是否有回放容器；
- 是否有合成输入和黄金炮测试；
- 是否能在装置外部署；
- 许可与出口管制。

### 7.4 标定迁移是数字孪生的首要风险

很多诊断在论文中验证了物理原理，但电厂寿命周期还需要处理辐照、窗口/镜面污染、材料迁移、电子学漂移、传感器更换与几何重测。数字孪生不应只保存“测量值”，还必须保存：

- 原始信号；
- 标定数据和有效期；
- 几何/响应矩阵版本；
- 通道健康与失效原因；
- 反演先验、残差和协方差；
- 原子/核数据版本；
- 软件、模型和配置哈希。

### 7.5 反演结果不是直接真值

rtEFIT、反射计、层析、FIDA、Balmer、IR 热流等都存在病态反问题。网站应明确区分：

- 原始观测；
- 标定后的工程量；
- 模型依赖反演量；
- 多诊断融合状态；
- 控制/决策使用量。

每一级都应携带不确定度、适用域和质量标志。

### 7.6 安全与保护证据缺口

本表 D5 为零。实时诊断、热斑告警、中子功率或逃逸电子监测可能服务控制/保护，但论文通常没有完整安全生命周期证据。进入机器保护或核安全用途前，还缺：

- 安全需求与危害分析；
- 独立性/冗余与共因失效评估；
- 诊断覆盖率和故障注入；
- 确定性时延与最坏情况执行时间；
- 配置与变更治理；
- 失效安全策略；
- 独立 V&V 与审批记录。
