# Fusion Data：MDSplus / IMAS 延后接入分析备忘

## 1. 本次决策

本次开发只完成 EXL-50U 主机测点叠加与管理，**不把 MDSplus、IMAS 或 H5 数据接入 `/fusion-data` 运行时**。当前分析结论先固化为本备忘，待数据边界、网关和展示合同完成后再单独实施。

这样可以避免把内部地址、连接凭据或未经审核的真实实验数据带入公共浏览器包，也避免在测点功能验收期间同时改变数据访问链路。

## 2. 已确认的数据路径

当前体系包含两个用途不同、但应保持可追溯关系的数据面：

- **IMAS H5 权威数据**：保留 IDS 的完整层级、AOS、误差、有效性和多维数组，是完整数据交付与复核的权威来源；
- **只读 MDSplus 镜像 / 时序投影**：面向快速读取单通道数值与维度，适合曲线浏览，但不是完整 IMAS 结构的替代品。

浏览器不能也不应直接连接内部 mdsip/TCP 服务。公共前端未来只能访问受控 HTTPS 网关，由服务端完成网络隔离、权限、查询校验、降采样、审计与错误归一化。内部主机名、IP、端口、用户名、令牌、存储路径和数据库凭据不得写入客户端 bundle、静态 JSON、HTML、source map 或公开日志。

## 3. 必须保留的追溯链

任何曲线、快照或下载结果都必须能够从页面回溯到以下标识：

```text
shot
  -> dataset_id
  -> IDS / ids_name
  -> occurrence (occ)
  -> run
  -> signal/path 或 H5 内字段路径
```

其中：

- `shot` 只标识炮号，不能单独确定数据版本；
- `dataset_id` 应完整表达或关联 `shot + IDS + occ + run`，带分隔符时应作为查询参数安全编码，避免 URL 路径歧义；
- `occ` 区分同一 IDS 的并存实例，`run` 区分处理或发布版本；
- MDSplus path 与 H5 字段 path 是两种投影，页面应展示其可追溯映射，而不是把二者混为一个字段；
- “推荐版本”也必须保留实际 `occ/run`，不能只显示一个模糊的 latest。

前端快照至少应携带：数据集标识、信号标识、时间范围、点数/降采样、单位、来源类型、生成时间、网关响应版本和可用的内容哈希或 ETag。

## 4. 数据语义与异常边界

### 4.1 H5 与镜像职责

- 需要完整 IDS 结构、AOS、误差、有效性或非时序多维量时，以 H5 为准；
- 需要快速显示已批准的一维/二维时序时，可用只读镜像经 HTTPS 网关投影；
- 网关不得用镜像中缺少的字段拼造一个“完整 IMAS”响应；
- 相同数据的 H5 与时序投影应能通过数据集版本和字段映射相互核对。

### 4.2 equilibrium 特殊维度

`equilibrium` 不能套用“所有字段最后一维都是时间”的通用假设。电流、时间片、磁通坐标和剖面量可能具有不同维度语义；`QPSI`、`PSI`、`PRES`、`F` 等字段的坐标轴需由服务端明确返回。前端必须根据响应中的维度名称、形状和坐标数组渲染，不能仅调用通用 `dim_of` 后把结果标为时间。

### 4.3 单位

单位优先取受控 HTTPS API 返回的审核字段；若底层镜像不含单位，应使用经过版本管理和审核的 IDS/信号映射表回填，并注明映射版本。前端不得根据名称猜单位，也不得把空单位自动替换为常见单位。值、误差、坐标轴和导出文件必须使用同一单位合同。

### 4.4 缺失与错误

未处理、未镜像、`occ/run` 无数据、节点不存在、字段为空、权限不足和网关错误必须是可区分状态。任何情况下都不得用零值、随机曲线、平滑插值或旧炮数据填充真实数据空缺。特别要防止长驻服务残留树状态导致请求错误炮号时返回旧数据；网关必须先验证炮号和数据集已登记且版本匹配，再读取底层数据。

## 5. 面向 `/fusion-data` 的目标架构

```text
公共浏览器
  -> 同源或受信任域名的 HTTPS API
     -> 身份与装置/数据集授权
     -> 查询白名单、范围限制、降采样与审计
     -> IMAS H5 权威存储（完整数据/受控下载）
     -> 只读 MDSplus 镜像（已审核时序投影）
```

公共页面不保存服务凭据，不直接发 mdsip 请求，也不代理任意底层表达式。信号查询应采用结构化参数白名单，不接受由浏览器拼接并透传的任意 TDI/path。大文件下载、受限诊断和精确实验数据应使用鉴权、短期授权与服务端审计；公开快照则使用经过审批、内容固定且可校验的版本化产物。

## 6. 建议的三阶段实施

### 阶段一：真实只读快照

- 选择少量已经批准的 EXL-50U 炮号、IDS 和信号；
- 由受控离线任务生成版本化 JSON/Arrow/Parquet 或切片文件，并附追溯元数据、单位、维度和哈希；
- 用真实快照替换 `/fusion-data` 的示例数据，明确“快照时间”和“非实时”状态；
- 先完成曲线、维度、缺失状态、下载和双端一致性验收。

### 阶段二：受控 HTTPS 时序网关

- 接入数据集目录、信号目录和有限的读数据端点；
- 服务端解析 `shot/dataset_id/IDS/occ/run/path`，执行白名单、范围、点数和降采样限制；
- 返回明确的单位、维度、缺失原因、来源版本与审计 ID；
- 增加身份、授权、速率限制、缓存策略、可观测性和安全测试。

### 阶段三：完整 IMAS 与受控下载

- 为完整 H5/IDS 增加权限分级、异步导出、短时下载和审计；
- 对 equilibrium、剖面、二维/多维数组建立专用展示组件；
- 建立 H5 权威数据与 MDSplus 投影的一致性抽查；
- 在明确公开、登录可见和内部受限三类数据边界后，再扩展炮号与诊断覆盖。

## 7. 正式启动前的门禁

后续开始运行时合入前，至少确认：

1. 哪些炮号、IDS、信号与精度允许公共双端发布，哪些必须登录或仅限内网；
2. 统一的 `dataset_id / occ / run / path` 查询与展示合同；
3. HTTPS 网关的域名、认证、授权、审计、限流、超时和错误模型；
4. H5 权威版本、只读镜像刷新策略和两者一致性验证；
5. 单位与维度映射表的责任人、版本和审核流程；
6. equilibrium 等特殊 IDS 的专用维度测试；
7. 私有地址与凭据不进入 bundle、静态资源、日志及错误页面的自动检查；
8. 国内站点与 OpenAI Sites 使用同一前端版本、同一公开快照和同一 API 合同。

在以上门禁完成前，`/fusion-data` 不应声称已实时连接 MDSplus/IMAS，也不应以演示曲线冒充 EXL-50U 实验数据。
