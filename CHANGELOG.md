# Changelog

All notable project changes are recorded here. Dates use Asia/Shanghai calendar dates.

## [1.0.0] - 2026-08-10

### Added

- FusionDigital community portal with physics, engineering, AI-native and global-facility routes.
- Searchable AI-native landscape covering 71 unique works across nine knowledge domains.
- Downloadable physics, engineering and AI-native reports plus structured JSON/CSV data.
- Maintainable AI-native source records, normalization, audit and Word-report scripts.
- Contributor guide, architecture, content-maintenance, Codex workflow, security and release documentation.
- Pull Request template, CODEOWNERS and cross-platform GitHub Actions quality gates.
- Third-party asset notice and initial publication-figure manifest.

### Changed

- Project package metadata now identifies FusionDigital instead of the vinext starter.
- Development and build commands are portable across Windows, macOS and Linux.
- AI-native generation uses an explicit source manifest and fixed edition date for deterministic rebuilds.

### Known limitations

- Physics, engineering and facilities content does not yet have the same fully normalized source-to-report pipeline as AI-native research.
- Several source-type, deployment and applicability metadata fields remain intentionally unclassified.
- Repository licensing requires separate decisions for code, data, reports and images.
- Large binary reports and figures increase repository size and require a future storage strategy.
